# To-Do App

## Problem Statement

Managing daily tasks can become difficult when there is no simple way to record, organize, and track completed activities. This project provides a command-line tool for managing tasks directly from the terminal.

## Project Goals

- Create and manage tasks using Bash.
- Track completed and pending tasks.
- Organize tasks by priority.
- Practise Bash functions, conditional statements, file handling, and command-line arguments.

## Tech Stack

- Bash
- Linux Terminal
- Standard Linux utilities

## Features

- Add new tasks.
- List all tasks.
- Mark tasks as completed.
- Delete tasks.
- Assign low, medium, or high priority.
- Store tasks in a local text file.

## Usage Examples

```bash
./todo.sh add "Learn Bash"
./todo.sh add -p high "Complete assignment"
./todo.sh list
./todo.sh done 1
./todo.sh delete 2
./todo.sh help
```
